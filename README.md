# Customer Net Sales & Market Performance Analysis

## Project Overview

This project focuses on analyzing customer-wise and market-wise
sales performance using Microsoft Excel.

The project includes interactive Pivot Table reports that help
analyze sales across different years, customers, markets, regions,
and divisions.

The reports provide insights into customer net sales performance
and market performance against targets.

## Objectives

- Analyze customer-wise net sales performance.
- Analyze market-wise sales performance.
- Compare sales across 2019, 2020, and 2021.
- Compare 2021 sales performance against 2020.
- Analyze market performance against targets.
- Use filters to analyze specific regions and divisions.
- Create structured and interactive Excel reports.
